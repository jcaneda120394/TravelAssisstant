# Privacy Policy (draft)

**TravelAssistant** ("we", "the app") helps travelers plan and navigate trips.

## Data we may collect

- Account information (email, name) via Supabase Auth
- Travel preferences you provide during onboarding
- Trip, itinerary, expense, and saved-place data you create
- Approximate or precise location **only when you grant permission** and use location features
- Diagnostics/analytics events (without unnecessary precise historical location)

## How we use data

- Provide trip planning, directions, recommendations, and AI assistance
- Improve reliability and security
- Support collaboration features you enable

## AI and third parties

AI responses may use tool/API data (places, transport, weather, etc.). Live operational facts come from providers — not model invention. Provider privacy policies also apply.

## Storage and security

- User content is protected with authentication and row-level security where Supabase is used
- Sensitive travel documents must use private storage buckets
- Secrets are not embedded in the mobile client

## Your choices

- Deny location permission and still use core features
- Sign out / delete account (when account deletion flow is enabled in production)
- Disable notifications
