# App Store / Play Store release checklist

- [ ] Final app name, subtitle, keywords
- [ ] Production icons + splash
- [ ] Screenshots (6.7", 6.5", 5.5", Android phone/tablet as required)
- [ ] Privacy Policy URL live
- [ ] Terms URL live
- [ ] Support URL / email
- [ ] Data safety / App Privacy nutrition labels
- [ ] Location / tracking disclosures accurate
- [ ] Production Supabase + Edge Functions
- [ ] `EXPO_PUBLIC_USE_MOCK_PROVIDERS=false`
- [ ] Sentry + PostHog production keys
- [ ] EAS production build (`eas build --platform all --profile production`)
- [ ] TestFlight / internal testing track
- [ ] Store listing localization (at least English)
- [ ] Age rating questionnaire
- [ ] Submit iOS + Android
